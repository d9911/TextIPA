# Файлы и библиотека

«Встроенные примеры» показывает JSON, TXT и Markdown из `examples`, включая подпапки. Выберите файл — приложение создаст редактируемую копию в localStorage браузера. Для TXT/Markdown выбирается язык текста; JSON уже содержит язык. Исходный файл в `examples` не изменяется при редактировании. Каталогу нужен работающий локальный сервер; импортированные ранее тексты доступны в библиотеке и офлайн.

Загрузить свой файл можно кнопкой «Загрузить файл» слева. Скачать выбранную рабочую копию можно кнопкой «Текущий текст · JSON» на панели либо через «Экспорт» над читалкой:

- JSON текущего текста сохраняет IPA, перевод, паузы, блоки, заметки и отметки.
- JSON библиотеки сохраняет все тексты и настройки.
- TXT содержит только текст фраз.
- Markdown создаёт лист для чтения с IPA и переводом.

Загрузка в браузере скачивает файл; автоматически записать его обратно в папку проекта приложение не пытается. Чтобы добавить новый встроенный пример, положите файл в `examples` вручную. При следующем открытии каталога он появится в списке.

## Формат JSON текущего текста

Это минимальный пример формата, который принимает `validateProject` в `src/domain/library.ts`:

```json
{
  "id": "my-script",
  "title": "Мой текст",
  "language": "es",
  "dialect": "es-ES",
  "translationLanguage": "ru",
  "updatedAt": "2026-10-07T12:00:00.000Z",
  "phrases": [
    {
      "id": "phrase-1",
      "block": "Вступление",
      "text": "Hola a todos.",
      "translation": "Всем привет.",
      "ipa": "",
      "ipaStatus": "empty",
      "pauseMs": 1000,
      "done": false,
      "note": ""
    }
  ]
}
```

Язык: `ru`, `en` или `es`. Произношение: `ru-RU`; `en-GB`/`en-US`; `es-ES`/`es-419`. Статус IPA: `empty`, `draft` или `reviewed`. ID фраз должны быть уникальными в тексте. Для файла, созданного другой программой, проще взять структуру из экспорта текущего текста; произвольная структура JSON не преобразуется автоматически.

Идентичный импорт открывает уже существующую копию. Изменённая версия сохраняется отдельно, не затирая предыдущую. Очистка localStorage удаляет библиотеку этого адреса; JSON-экспорт нужен как резервная копия.

## Перевод при чтении

В настройках «?» включите «Показывать перевод при чтении». Перевод выбранной фразы появится под текстом и IPA; в общем списке появятся редактируемые поля перевода. Переключатель сохраняется в localStorage и резервной копии. `translation` у фразы и `translationLanguage` у проекта необязательны: старые JSON-файлы открываются без изменений. Если перевода нет, читалка сообщает об этом. Перевод берётся из файла или вводится вручную; автоматического API перевода нет.

Публичный пример: `examples/kolobok-es-ru.json` — короткий авторский пересказ «Колобка» на испанском с русским переводом и черновой IPA, подготовленной локальным eSpeak NG. Личный `examples/cable-es.json` остаётся на диске и доступен локально, но исключён через `.gitignore`.

## Языковые колонки

«Языки и колонки» рядом с названием текста задаёт основной язык и дополнительные колонки через коды языков (`es`, `en`, `ru`, `fr`, `pt-BR`). Эти параметры также доступны при создании текста. До восьми колонок; порядок сохраняется в `columnLanguages`. Переключатель показа перевода в «?» скрывает или показывает дополнительные версии. На широком экране колонки стоят рядом, на узком — друг под другом.

Текст и IPA основной версии остаются в полях `text`, `ipa`, `ipaStatus` фразы. Дополнительные версии лежат в `translations`, например:

```json
{
  "en": { "text": "Hello.", "ipa": "[həˈləʊ]", "ipaStatus": "draft" },
  "ru": { "text": "Привет.", "ipa": "", "ipaStatus": "empty" }
}
```

Старые `translation` и `translationLanguage` продолжают читаться. Выбор другого основного языка сохраняет прежнюю версию в `translations`; скрытие колонки не удаляет её данные. JSON сохраняет все версии, Markdown — выбранные колонки. Автоматическая IPA обрабатывает выбранные колонки `es`, `en`, `ru`; для других языковых кодов доступна ручная IPA. Переводы автоматически не создаются. Озвучка основного языка зависит от установленных локальных голосов браузера.

Файл `kolobok-es-ru.json` теперь содержит ES/EN/RU: испанский пересказ, английскую версию и русский перевод с отдельной черновой IPA для каждой версии.
