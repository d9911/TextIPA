# Text IPA

Локальное приложение для подготовки и репетиции озвучки. Текст слева, IPA справа, паузы и заметки под каждой фразой. Интерфейс на русском, испанском и английском.

[English](README.md) · [Español](README.es.md)

## Запуск

Нужны Node.js 24+, npm и Make. Для автоматической IPA нужен `espeak-ng` в PATH либо полный путь в переменной `ESPEAK_BIN`. На этом Mac движок уже установлен в `/opt/homebrew/bin/espeak-ng`.

```sh
cd "$HOME/Movies/DaVinci Resolve/españolTextIPA"
make
```

Первый запуск устанавливает зависимости по `package-lock.json`, собирает приложение и открывает браузер. Адрес: [http://127.0.0.1:8767/](http://127.0.0.1:8767/). Остановка: Ctrl+C в терминале. Старый адрес `/ES_PAUSAS_IPA.html` перенаправляется в приложение.

```sh
make dev       # разработка с обновлением при правках
make init      # только установка зависимостей
make check     # TypeScript, тесты, форматирование
make build     # сборка в dist
make format    # Prettier
NO_OPEN=1 make # запуск без открытия новой вкладки
PORT=8768 make # другой порт; это отдельное хранилище браузера
```

Повторный запуск переиспользует сервер этого же проекта и режима. Если порт занят другим приложением или режимом, запуск сообщает об ошибке; процесс не останавливается автоматически. Для генерации IPA используйте сервер приложения: обычный сервер статических файлов не предоставляет `/api/ipa`.

Тема первого запуска — системная, язык выбирается по списку языков браузера (RU/EN/ES, иначе русский). Сохранённые настройки имеют приоритет. Кнопка «?» открывает общую справку IPA: символы, написания, примеры и объяснение произношения с выбором RU/EN/ES. Справка поддерживает поиск.

## Подготовка записи

1. Нажмите «Новый текст», выберите язык и вставьте сценарий либо загрузите TXT, MD или JSON. Абзацы становятся блоками; заголовки Markdown сохраняют названия блоков.
2. Выберите произношение: испанский Испании или seseo, английский Британии или США, русский. «Подготовить IPA» заполняет черновики через локальный eSpeak NG. Проверенные вручную фразы пропускаются.
3. Исправьте текст, IPA, паузы и заметки. После изменения текста старая IPA очищается. Отметка «IPA проверена мной» означает вашу собственную проверку.
4. Репетируйте в режиме чтения: стрелки переключают фразы, пробел запускает или останавливает таймер. Размер текста, темп и длительность пауз настраиваются. Отмечайте готовые фразы.
5. Экспортируйте JSON проекта или резервную копию всей библиотеки. Markdown пригоден как лист для чтения, JSON — для восстановления редактируемых данных.

Паузы нового текста предлагаются программой: 0,4 с после запятой, точки с запятой и двоеточия; 1 с после конца предложения; 2 с после абзаца. Это исходные настройки, их можно менять. Таймер рассчитывается как `число слов / слов в минуту × 60 + пауза × множитель` и не является таймкодом записи.

## Сохранение и импорт

Данные сохраняются автоматически в `localStorage` этого браузера для текущего адреса. Они не записываются автоматически в папку проекта. Очистка браузера, другой профиль или другой порт меняют доступ к библиотеке: сохраняйте JSON через «Экспорт → Резервная копия».

Импорт принимает собственный JSON проекта, резервную копию библиотеки и прежний `segments_ipa.json`. Резервная копия восстанавливает настройки и активный проект, объединяя библиотеку. Точные повторения текста, диалекта, блоков, IPA и пауз не добавляются; изменённая версия с совпадающим ID сохраняется отдельно с пометкой `(import)`. При ошибке файл не применяется частично. Отмена последних правок доступна до перезагрузки страницы.

Лимиты: файл до 5 МБ, вставленный текст до 500 000 символов, до 300 проектов, до 10 000 фраз в проекте, до 1 500 символов в одной фразе. Встроенный пример `examples/kolobok-es-ru.json` содержит короткий пересказ «Колобка» на испанском, английском и русском с отдельной черновой IPA. Личный файл про кабель остаётся локально, но исключён из Git.

## IPA и звук

Автоматическая IPA — подсказка для репетиции, требующая проверки, особенно для чисел, брендов и заимствований. Испанский результат дополнительно нормализуется; вариант seseo заменяет θ на s, но не моделирует все региональные особенности Латинской Америки. Английский и русский используют вывод выбранного голоса eSpeak NG. Я не могу подтвердить фонетическую точность каждой автоматически полученной фразы.

«Прослушать фразу» использует только голоса браузера с `localService=true` для выбранного языка. Доступность зависит от системы и браузера; при отсутствии такого голоса приложение сообщает об этом. Это пример произношения, а не экспорт готовой аудиодорожки. В настройках «?» можно включить показ перевода из файла; перевод редактируется и сохраняется вместе с текстом. Распознавание записи, автоматический перевод и оценка вашего произношения в эту версию не входят.

Текст обрабатывается локальным сервером на `127.0.0.1`. Для установки npm-зависимостей нужен интернет при отсутствии локального кеша; подготовка IPA работает локально после установки движка. Внешних шрифтов, аналитики и API перевода в приложении нет.

## Навигация по URL

Параметры `project`, `block`, `phrase`, `q` и `focus=1` восстанавливают текст, блок, фразу, поиск и режим чтения. Проекты и фразы адресуются по сохранённым ID; изменение порядка фраз не меняет цель ссылки. Кнопки «Назад»/«Вперёд» и история браузера переключают выбор, сохраняя правки. Если выбранный объект отсутствует, приложение открывает доступный и показывает уведомление. Ссылка работает с библиотекой данного браузера; для переноса текстов используйте JSON.

Границы модулей и правила параметров описаны в [ARCHITECTURE.md](docs/ARCHITECTURE.md). Типы данных находятся в `src/types/domain.ts`, API — в `src/types/api.ts`, URL-состояние — в `src/app/navigation.ts`, DOM-компоненты — в `src/shared/ui/controls.ts`, интерфейс справки — в `src/features/pronunciation/dialog.ts`.

## Мастерская голоса

Идея Text IPA — подготовить сценарий перед записью: выстроить текст, прочитать звуки, найти паузы и отрепетировать. Название не привязано к испанскому; текущие варианты текста и IPA поддерживают испанский, английский и русский.

Все фразы остаются в непрерывной ленте, в том числе в режиме чтения. Блоки служат для перехода к первой фразе, остальные не скрываются. Поиск может сузить список; после его очистки снова виден весь сценарий. Новая фраза получает фокус и появляется с анимацией.

Выпадающие списки оформлены в цвет темы: стрелка поворачивается, работают клавиши ↑/↓, Home/End, Enter, Escape, поиск по начальной букве и закрытие кликом снаружи. Анимации учитывают системное уменьшение движения. В настройках отдельно регулируются размеры текста и IPA.

Для IPA поставляется локальный бесплатный [Charis 7.000](https://software.sil.org/charis/download/), неизменённый regular WOFF2 по [SIL OFL 1.1](public/fonts/charis/OFL.txt). Покупка лицензии не нужна; её текст включён рядом со шрифтом. [Поддерживаемые символы](https://software.sil.org/charis/charset/) включают IPA и комбинируемые знаки. Сеть при чтении не используется. Пользовательская лицензия приложения остаётся отдельной и не меняется. Шрифт улучшает отображение, но не добавляет пропущенные фонемы в результат генератора.

Повторный `make s` проверяет идентификатор приложения, реальный путь проекта и режим сервера. Если уже работает production этого проекта, обновляет сборку и открывает прежний адрес. При чужом процессе или другом режиме показывает понятное сообщение; автоматически процессы не завершает. Адрес и ключ библиотеки сохраняются.

## PWA, прокрутка и размер репозитория

Production-сборка (`make s`) содержит manifest, PNG-иконки и service worker. Установить приложение можно через меню браузера («Установить приложение» / «Добавить на экран Домой»); доступность зависит от браузера. Используйте localhost/127.0.0.1 либо HTTPS. `make dev` не регистрирует worker.

После первого онлайн-открытия интерфейс, Charis и справка доступны офлайн. Тексты остаются в localStorage; это не резервная копия. Для новой IPA и загрузки встроенного примера нужен работающий локальный сервер. API-ответы и импортированные файлы не кешируются. Обновление активируется после закрытия всех окон приложения: затем откройте его снова.

Стрелки и таймер меняют фразу в окне читалки без прокрутки. Чтобы дополнительно перейти к её строке, включите «Прокручивать к фразе при переключении» в настройках. Флажок выключен по умолчанию и сохраняется. Переход по блоку остаётся явным переходом к строке.

Справка содержит общую базу символов, написаний и примеров; dropdown «Язык подсказок» меняет только объяснение на RU/EN/ES. Это краткая справка, а не полный алфавит IPA. В таблице есть ссылки на фонетические источники. Прослушивание использует только локальный голос Web Speech API: платные токены и облачный TTS в приложении не подключены. Если подходящего локального голоса нет, программа сообщает об этом.

`node_modules`, `dist`, кеши, записи, архивы и `output` исключены из Git. Повторные PNG-снимки проверок перенесены в `output/archive/screenshots`; в документации сохранены `app.jpg` и `guide-dark.jpg`. Тексты лицензий и `package-lock.json` сохранены. Изменения Git index и публикацию выполняйте вручную: `.gitignore` не удаляет уже добавленные в index файлы.

## Рабочее пространство и файлы

Левая панель сворачивается в узкую полосу с иконками; полные названия появляются в подсказках при наведении или фокусе с клавиатуры. Она остаётся видна при прокрутке и в режиме чтения. Кнопка «?» в хедере открывает настройки: закрепить хедер, свернуть панель, прокручивать к выбранной фразе и открыть справку IPA. Настройки сохраняются.

«Встроенные примеры» находит JSON/TXT/MD в `examples`, включая подпапки. Это редактируемые копии в библиотеке браузера. Экспорт выбранной копии доступен прямо слева; меню над читалкой также содержит TXT, Markdown и резервную копию библиотеки. [Форматы и порядок работы](docs/FILES.md).

«Языки и колонки» рядом с названием задаёт основной язык и дополнительные версии; коды также задаются при создании текста. Колонки стоят рядом на широком экране и идут друг под другом на узком. Можно использовать другие языковые коды: ES/EN/RU поддерживают автоматическую IPA, остальные — ручную. Скрытые версии сохраняются в JSON. См. [формат файла](docs/FILES.md).
